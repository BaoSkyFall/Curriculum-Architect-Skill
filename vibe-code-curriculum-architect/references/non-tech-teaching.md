# Non-Technical Learner Reference

## Guardrails

- Define every new technical term before using it repeatedly.
- Use one stable example across lessons so learners can focus on the new idea.
- Make inputs, outputs, and failure states visible.
- Explain what the learner can safely ignore at the current depth.
- Treat AI-generated code as an artifact to inspect, not authority to trust.

## Useful Mental Models

- Frontend: the interface the person uses.
- Backend: the service that applies rules and coordinates data.
- API: a defined request and response boundary.
- Database: persistent structured memory.
- LLM: a probabilistic language service operating on provided context.

Replace an analogy when it starts hiding an important technical boundary.
