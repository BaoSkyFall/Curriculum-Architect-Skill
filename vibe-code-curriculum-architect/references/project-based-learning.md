# Project-Based Learning Reference

Every lab should produce a small artifact that survives into the capstone:

```text
concept -> tiny build -> inspect result -> improve -> integrate
```

## Lab Requirements

- one clear goal;
- observable expected output;
- only known prerequisites;
- a short success check;
- common errors and a debugging path;
- an optional stretch goal.

Do not introduce a new platform merely to make a lab look impressive. Prefer one continuous project with incremental complexity over disconnected demos.
