# Curriculum Review Rubric

Review each dimension as `clear`, `needs work`, or `critical` and cite the affected module or artifact.

- Goal alignment: outcomes match the stated learner and capstone.
- Prerequisite integrity: each jump has the required concepts.
- Difficulty progression: complexity increases in manageable steps.
- Concept coverage: core architecture is present without needless depth.
- Practicality: labs are observable, bounded, and runnable.
- Tool longevity: choices have evidence, alternatives, and freshness dates.
- Project integration: modules contribute to one coherent capstone.
- Assessment quality: learners explain and debug systems, not only syntax.
- Non-tech accessibility: terminology and setup are introduced progressively.

Report: critical issues, warnings, suggestions, assumptions, and the smallest repair sequence.
