# Course Specification

Course name: Vibe Coding for Non-Technical Learners
CURRICULUM_VERSION: v0.1
Audience: confident computer users with no software-engineering background
Prerequisites: file management, browser use, and basic AI-chat experience
Duration: 40 hours
Teaching format: guided demos, paired labs, and one continuous capstone

## Purpose

Help learners understand how modern AI applications fit together and use an AI coding agent to build a small personal-knowledge chat application.

## Learning Outcomes

Students can explain frontend, backend, API, database, LLM, retrieval, agents, skills, and MCP; trace a request through the system; build and debug a small integrated application; and justify major tool choices.

## Core Concepts

Software boundaries, request/response, persistent data, context, agent tools, decomposition, verification, ingestion, retrieval, and error handling.

## Tools and Access

Choose one coding-agent track, one model provider, one simple backend stack, and one storage path after current research.

## Capstone

Personal Knowledge AI Chat Application.

## Assessment Strategy

Architecture explanations, observable lab outputs, debugging notes, and a capstone walkthrough.
