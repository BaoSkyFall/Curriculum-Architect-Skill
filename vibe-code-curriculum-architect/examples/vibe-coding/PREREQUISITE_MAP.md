# Prerequisite Map

```text
Software mental model
  -> frontend/backend boundaries
  -> HTTP, API, and JSON
  -> backend endpoint
  -> LLM request
  -> chat interface
  -> database persistence
  -> data ingestion
  -> chunking and embeddings
  -> retrieval
  -> RAG integration
  -> capstone verification
```

Agent concepts begin after the software mental model and support every later build step.
