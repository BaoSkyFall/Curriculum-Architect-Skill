# Curriculum Decisions

## ADR-001: Use One Coding-Agent Track

Date: 2026-10-01
Status: accepted

### Question

Should learners study both Claude Code and OpenAI Codex?

### Decision

No. Teach shared agent concepts and choose one implementation track for the main course.

### Context and Evidence

Teaching both adds setup and interface complexity without adding a distinct mental model.

### Alternatives Considered

Teach both tools in parallel; rejected because it divides practice time.

### Consequences

The instructor must choose and verify one track before delivery. The other may appear in an optional comparison lesson.

### Revisit When

A second track teaches a genuinely distinct capability required by the course outcomes.
