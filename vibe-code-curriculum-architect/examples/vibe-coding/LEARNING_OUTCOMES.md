# Learning Outcomes

By the end of the course, students can:

1. Draw and explain the path from user action to backend response.
2. Describe the roles of frontend, backend, API, database, LLM, and retrieval.
3. Direct an AI coding agent with bounded tasks, context, and verification.
4. Build a chat interface connected to a backend and model API.
5. Ingest a small document set and retrieve relevant context.
6. Diagnose common configuration, request, data, and model failures.
7. Explain the final application's architecture and limitations.
