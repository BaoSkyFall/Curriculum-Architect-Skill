# Assessment: Explain the Request Path

Target lesson or module: How a Software System Responds
Evidence type: short oral explanation plus diagram

## Prompt

When a user sends a message in a chat application, explain what happens until the answer appears.

## Expected Evidence

The learner identifies the interface, request, processing service, optional stored data, response, and final render in a plausible order.

## Rubric

| Criterion | Emerging | Sufficient | Strong |
|---|---|---|---|
| System explanation | Lists parts without flow | Explains the main request and response path | Explains boundaries and likely failures |
| Vocabulary | Uses terms inconsistently | Uses core terms correctly | Connects terms to observable behavior |

## Feedback Notes

Correct the mental model before correcting terminology.

## Capstone Connection

This explanation becomes the first draft of the capstone architecture walkthrough.
