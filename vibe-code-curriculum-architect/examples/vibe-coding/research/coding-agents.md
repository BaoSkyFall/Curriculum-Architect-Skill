# Coding Agent Research Note

## Research Question

Which coding-agent track best supports the current learner cohort and instructor environment?

## Required Checks

- official documentation and supported platforms;
- current pricing and account access;
- skills, MCP, subagent, and verification support;
- installation complexity;
- release activity and breaking changes;
- instructor familiarity and classroom recovery path.

## Decision Rule

Choose the simplest supported track that exposes the required agent concepts. Record evidence in `TECH_RADAR.md` and the teaching choice in `DECISIONS.md`.
