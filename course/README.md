# Vibe Coding cho người non-tech: Xây dựng ICP Chatbot

Đây là bản giáo án v0.1 cho khóa 12 buổi, mỗi buổi 90 phút. Học viên đi từ mô hình tư duy phần mềm đến một chatbot hỗ trợ xây dựng **Ideal Customer Profile (ICP)** bằng dữ liệu CRM, dữ liệu bổ sung, phân tích pattern, chấm điểm và tìm công ty tương tự.

## Cách dùng

- Đọc `COURSE_SPEC.md` và `LEARNING_OUTCOMES.md` trước khi dạy.
- Dùng `CURRICULUM_MAP.md` để theo dõi sản phẩm qua từng buổi.
- Dùng `TECH_RADAR.md` và thư mục `research/` để kiểm tra lại tool trước mỗi khóa.
- Mỗi thư mục trong `lessons/` là một gói dạy 90 phút gồm mục tiêu, mô hình tư duy, demo, bài lab, kiểm tra hiểu và bài tập.

## Giả định

- Học viên biết dùng trình duyệt, tệp/thư mục và công cụ chat AI; chưa cần biết lập trình.
- Dùng dữ liệu giả lập hoặc dữ liệu đã ẩn danh. Không đưa CRM thật, API key hoặc PII vào repo/lab.
- Lộ trình chính là runtime agent tương thích Codex/Claude + MCP; giáo viên chọn **một** track triển khai trước ngày khai giảng.
- Ngăn xếp lab đề xuất: React/Vite, Node.js API tối giản, SQLite hoặc Supabase/Postgres, một LLM API và một kho retrieval đơn giản. Không bắt học viên học sâu framework.
