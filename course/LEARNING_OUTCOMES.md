# Chuẩn đầu ra

Sau khóa học, học viên có thể:

1. Vẽ và giải thích luồng `user → frontend → backend API → database/LLM → response` bằng ngôn ngữ của mình.
2. Phân biệt frontend, backend, API, cơ sở dữ liệu, LLM, pipeline dữ liệu, retrieval, agent, skill và MCP.
3. Chọn một runtime coding agent, viết task có context/tiêu chí nghiệm thu và kiểm tra output thay vì tin mù quáng.
4. Chia một tính năng thành task nhỏ cho một agent hoặc nhiều subagent, biết khi nào không cần đa agent.
5. Biến một sản phẩm thiết kế thành frontend có trạng thái đang tải, trống, thành công và lỗi.
6. Tạo và gọi một endpoint backend với JSON, biến môi trường và xử lý lỗi cơ bản.
7. Gọi LLM từ backend với system/user messages, structured output và giới hạn dữ liệu nhạy cảm.
8. Thiết kế schema tối thiểu cho company, interaction, enrichment, score, tier và evidence.
9. Mô tả và chạy pipeline `raw → load → clean → transform → store → retrieve` trên dữ liệu CRM giả lập.
10. Giải thích embeddings, retrieval và RAG; biết rằng RAG không tự động làm dữ liệu đúng.
11. Kiểm tra scoring rule trên dữ liệu lịch sử bằng bảng kết quả và nêu false positive/false negative.
12. Demo ICP chatbot và giải thích mọi block, giới hạn, lỗi đã gặp cùng quyết định về tool.
